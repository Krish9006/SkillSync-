SkillSync

A "LinkedIn for Hackathons" - Connecting students with collaborators based on verified skills.

Social Platform Next.js 14 3D Graphics

The Challenge

In the academic and hackathon ecosystem, students struggle to find teammates with complementary skills. Existing platforms are too broad, and verify proficiency is difficult without seeing previous work. I needed to build a platform that makes "scouting" talent intuitive and engaging.

Technical Architecture

Frontend Next.js 14 (App Router), Tailwind CSS, Framer Motion, Three.js (@react-three/fiber).
Backend Node.js, Express.js architecture with RESTful API endpoints.
Database MongoDB (NoSQL) for flexible user profile schemas and connection requests.

Key Technical Problem Solved

Problem: Performance vs. Aesthetics Integrating rich 3D graphics (Three.js) usually kills load times and mobile performance. The initial build had a layout shift (CLS) of 0.4 and TTI of >3s.
Solution: Optimization Strategy I implemented dynamic imports for heavy 3D canvas components, reducing the initial bundle size by 40%. I also used low-poly models and limited real-time shadow casting to ensure a steady 60fps on mid-range devices.

Krishka Kitchen

A full-stack culinary community platform enabling real-time recipe sharing and social interaction.

Community App MERN Stack Authentication

The Challenge

Building a content-heavy application where users can not only view content but interact with it (User Generated Content). The challenge was creating a secure environment for users to register, post recipes, and interact (like/comment) in real-time without database bottlenecks.

Technical Architecture

Authentication Custom JWT implementation with secure HTTP-only cookies to prevent XSS attacks.
API Design MVC Pattern (Model-View-Controller) to separate business logic from routing.
Deployment Frontend on Vercel, Backend on Render. Handled CORS configurations and environment security.

Key Technical Problem Solved

Problem: Deployment & Environment Chaos Connecting a deployed frontend (Vercel) to a separate backend (Render) caused significant CORS (Cross-Origin Resource Sharing) issues and state persistence failures upon refresh.
Solution: Robust Configuration I re-architected the backend configuration to whitelist specific production domains and implemented a strict Environment Variable policy. I also created a "ping" service to keep the free-tier Render server warm, reducing cold-start latency for users.

RentAFellow

A Progressive Web App (PWA) focusing on platonic companionship and ethical social connection.

PWA UX Design Mobile First

The Challenge

Designing a social app that explicitly avoids the "dating/escort" stigma. The UI needed to be friendly, safe, and trustworthy ("Zero Creepiness"). Technically, it needed to feel like a native app on mobile devices without the friction of app store downloads.

Tech & Design Strategy

PWA Architecture Service Workers for offline caching and "Add to Home Screen" capability.
Modular Routing Implemented a scalable frontend router to handle dynamic categories (Movies, events, travel) efficiently.
UI/UX Used color psychology (Blues/Greens) and rounded, "soft" UI elements to evoke trust and platonic safety.

Key Technical Problem Solved

Problem: Mobile Responsiveness & Navigation Complex navigation menus often break on mobile screens. We needed a system that handled deep nesting (Category -> Profile -> Booking) without overwhelming the user.
Solution: Component Modularization I built a reusable, modular Navbar and Layout system. By decoupling the navigation logic from the page content, I ensured that the state (User Session) persisted smoothly during navigation transitions, creating a seamless "App-like" feel on the mobile web.
